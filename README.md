## 🚀 How to Use This Repository

### 1. Clone the repository

```bash
git clone https://github.com/abdul-aual/Codeforces-Solution.git
```

### 2. Open the project

```bash
cd Codeforces-Solution
```

### 3. Compile a solution

Choose a `.cpp` file and compile it using `g++`:

```bash
g++ -std=c++17 "1360B - Honest Coach.cpp" -o solution
```

### 4. Run the program

On Windows:

```bash
solution.exe
```

On Linux or macOS:

```bash
./solution
```

**Note:** The filename in the compilation command is an example. Replace it with the exact filename you want to compile. Some problems may require a different C++ standard depending on the implementation.

## 💡 How to Learn from These Solutions

If you are using this repository for practice:

1. Read the original problem statement on Codeforces.
2. Try solving the problem independently before viewing the code.
3. Study the implementation and understand why it works.
4. Analyze the time and space complexity where applicable.
5. Test the solution against edge cases and sample inputs.

The objective is not just to obtain an accepted answer, but to understand the reasoning behind the solution.
